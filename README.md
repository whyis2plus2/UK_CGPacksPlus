# CGPacksPlus
### A mod for ULTRAKILL that adds extra features to cybergrind pattern packs.

## Features
- Toggling individual patterns in a pattern pack
- Setting a custom display name for the pattern pack (see the [wiki](https://github.com/whyis2plus2/UK_CGPacksPlus/wiki) for more info)
- Setting a custom preview for the pattern pack (see the [wiki](https://github.com/whyis2plus2/UK_CGPacksPlus/wiki) for more info)
